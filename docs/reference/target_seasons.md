# Target seasons for data acquisition

Target seasons for data acquisition

## Usage

``` r
target_seasons(start = 2015L, end = 2025L)
```

## Arguments

- start:

  Integer. Start year of first season (default 2015).

- end:

  Integer. Start year of last season (default 2025).

## Value

Character vector of 4-digit season codes.
