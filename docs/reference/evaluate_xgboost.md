# Evaluate XGBoost model performance

Computes performance metrics for XGBoost predictions.

## Usage

``` r
evaluate_xgboost(fit, test_data)
```

## Arguments

- fit:

  A list from
  [`fit_xgboost()`](https://johngavin.github.io/footbet/reference/fit_xgboost.md).

- test_data:

  A tibble with feature columns and actual outcomes.

## Value

A list with accuracy, log loss, and confusion matrix (for
classification) or RMSE and MAE (for regression).
