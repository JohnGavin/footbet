# Determine stake from edge using tiered thresholds

Uses a small tolerance (`1e-9`) to guard against floating-point boundary
misses (e.g. [`seq()`](https://rdrr.io/r/base/seq.html) producing
`0.09999...` instead of `0.10`).

## Usage

``` r
oagd_stake(edge, tau_min = 0.05, tau_double = 0.1)
```

## Arguments

- edge:

  Numeric. Model edge over implied probability.

- tau_min:

  Numeric. Minimum edge to place 1-unit bet (default 0.05).

- tau_double:

  Numeric. Edge threshold for 2-unit bet (default 0.10).

## Value

Integer. Stake: 0, 1, or 2 units.
