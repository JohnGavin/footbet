# Compute rolling xG averages for each team

Calculates rolling mean expected goals for and against over a window of
recent matches, using only information available before each match.
Requires matches to have `home_xg` and `away_xg` columns from FBref.

## Usage

``` r
rolling_xg(matches_df, window = 5L)
```

## Arguments

- matches_df:

  A tibble with `match_date`, `home_team`, `away_team`, `home_xg`,
  `away_xg`.

- window:

  Integer. Number of past matches to include (default 5).

## Value

A tibble with columns `team`, `match_date`, `match_id`,
`rolling_xg_for`, `rolling_xg_against`, `rolling_xg_diff`.
