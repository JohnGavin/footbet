# Convert fractional odds to decimal

Convert fractional odds to decimal

## Usage

``` r
fractional_to_decimal(fractional_odds)
```

## Arguments

- fractional_odds:

  Character vector. Fractional odds (e.g., "3/2", "evens").

## Value

Numeric vector. Decimal odds.
