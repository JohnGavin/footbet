# Convert decimal odds to fractional

Convert decimal odds to fractional

## Usage

``` r
decimal_to_fractional(decimal_odds)
```

## Arguments

- decimal_odds:

  Numeric vector. Decimal odds (e.g., 2.50).

## Value

Character vector. Fractional odds (e.g., "3/2").
