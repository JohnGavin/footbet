# Wrap mermaid code in fenced block for README.md

Creates a GitHub-flavored markdown fenced code block that GitHub renders
natively as a diagram.

## Usage

``` r
wrap_mermaid_fenced(mermaid_code)
```

## Arguments

- mermaid_code:

  Character. Mermaid diagram code.

## Value

Character. Fenced mermaid code block.
