# Convert decimal odds to American

Convert decimal odds to American

## Usage

``` r
decimal_to_american(decimal_odds)
```

## Arguments

- decimal_odds:

  Numeric vector. Decimal odds.

## Value

Numeric vector. American odds (positive = underdog, negative =
favourite).
