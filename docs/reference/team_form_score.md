# Compute composite team form score

Combines multiple performance metrics into a single 0-100 score. Higher
scores indicate better recent form. This simplifies betting rule
thresholds compared to multi-factor conditions.

## Usage

``` r
team_form_score(
  rolling_gf,
  rolling_xg = NULL,
  elo,
  weight_goals = 0.3,
  weight_xg = 0.5,
  weight_elo = 0.2
)
```

## Arguments

- rolling_gf:

  Numeric. Rolling average goals for.

- rolling_xg:

  Numeric. Rolling average xG for (optional, uses goals if NA).

- elo:

  Numeric. Current Elo rating.

- weight_goals:

  Numeric. Weight for goals component (default 0.3).

- weight_xg:

  Numeric. Weight for xG component (default 0.5).

- weight_elo:

  Numeric. Weight for Elo component (default 0.2).

## Value

Numeric. Form score in range 0-100.

## Details

The default weights prioritize xG (50%) over goals (30%) and Elo (20%),
reflecting that xG is more predictive of future performance.

## Examples

``` r
# Strong team: high goals, high xG, high Elo
team_form_score(2.5, 2.8, 1750)
#> [1] 86.66667

# Average team
team_form_score(1.2, 1.3, 1500)
#> [1] 43.66667

# Weak team
team_form_score(0.8, 0.7, 1300)
#> [1] 25.66667
```
