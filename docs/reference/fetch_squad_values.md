# Fetch squad market values from Transfermarkt

Fetch squad market values from Transfermarkt

## Usage

``` r
fetch_squad_values(country, start_year = 2024L)
```

## Arguments

- country:

  Character. Country name.

- start_year:

  Integer. Season start year.

## Value

A tibble with team names and squad values.
