# Calculate overround (vig) from decimal odds

Calculate overround (vig) from decimal odds

## Usage

``` r
calc_overround(odds)
```

## Arguments

- odds:

  Numeric vector of decimal odds.

## Value

Numeric overround (e.g. 1.05 means 5% margin).
