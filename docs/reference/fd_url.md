# Build football-data.co.uk URL for a league/season CSV

Build football-data.co.uk URL for a league/season CSV

## Usage

``` r
fd_url(league_code, season)
```

## Arguments

- league_code:

  Character. League code (e.g. "E0", "D1").

- season:

  Character. Season code (e.g. "2324" for 2023/24).

## Value

Character URL.
