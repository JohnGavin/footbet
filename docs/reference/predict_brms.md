# Predict match outcome probabilities from a brms Poisson model

Uses posterior predictive distribution to compute 1X2, O/U, and AH
probabilities.

## Usage

``` r
predict_brms(model, home_team, away_team, max_goals = 10L, ndraws = 1000L)
```

## Arguments

- model:

  A `brmsfit` object from
  [`fit_brms_poisson()`](https://johngavin.github.io/footbet/reference/fit_brms_poisson.md).

- home_team:

  Character. Home team name.

- away_team:

  Character. Away team name.

- max_goals:

  Integer. Maximum goals to consider in score matrix (default 10).

- ndraws:

  Integer. Number of posterior draws to use (default 1000).

## Value

A list with components:

- `score_matrix`: Matrix of P(home=i, away=j) probabilities

- `prob_1x2`: Named vector c(H, D, A)

- `prob_ou`: Named vector c(over_25, under_25)

- `prob_ah`: Named vector with Asian handicap probabilities (if
  applicable
