# Compute combined accumulator odds

Calculates combined decimal odds for an accumulator bet.

## Usage

``` r
acca_odds(odds)
```

## Arguments

- odds:

  Numeric vector. Individual selection decimal odds.

## Value

Numeric. Combined decimal odds (product of all odds).
