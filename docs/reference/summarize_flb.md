# Summarize favourite-longshot bias

Provides a high-level summary of FLB patterns.

## Usage

``` r
summarize_flb(flb_df)
```

## Arguments

- flb_df:

  A tibble from
  [`detect_flb()`](https://johngavin.github.io/footbet/reference/detect_flb.md).

## Value

A tibble with FLB summary statistics.
